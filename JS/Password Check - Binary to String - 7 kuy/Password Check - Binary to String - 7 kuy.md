                <div class="markdown prose max-w-none mb-8" id="description"><h1 id="password-check---binary-to-string">Password Check - Binary to String</h1>
<p>A wealthy client has forgotten the password to his business website, but he has a list of possible passwords. His previous developer has left a file on the server with the name password.txt. You open the file and realize it's in binary format.</p>
<p>Write a script that takes an array of possible passwords and a string of binary representing the possible password. Convert the binary to a string and compare to the password array. If the password is found, return the password string, else return false (or <code>NULL</code> / <code>null</code>, depending on the language).</p>
