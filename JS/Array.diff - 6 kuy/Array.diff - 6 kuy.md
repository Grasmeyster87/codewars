<div class="markdown prose max-w-none mb-8" id="description"><p>Implement a function that computes the difference between two lists. The function should remove all occurrences of elements from the first list (<code>a</code>) that are present in the second list (<code>b</code>). The order of elements in the first list should be preserved in the result.</p>
<h2 id="examples">Examples</h2>
<p>If <code>a = [1, 2]</code> and <code>b = [1]</code>, the result should be <code>[2]</code>.</p>
<p>If <code>a = [1, 2, 2, 2, 3]</code> and <code>b = [2]</code>, the result should be <code>[1, 3]</code>.</p>
</div>

<div class="markdown prose max-w-none mb-8" id="description"><p>Реализуйте функцию, которая вычисляет разность двух списков. Функция должна удалять из первого списка (<code>a</code>) все вхождения элементов, присутствующих во втором списке (<code>b</code>). При этом порядок следования элементов из первого списка должен быть сохранен в результате.</p>
<h2 id="examples">Примеры</h2>
<p>Если <code>a = [1, 2]</code> и <code>b = [1]</code>, результатом будет <code>[2]</code>.</p>
<p>Если <code>a = [1, 2, 2, 2, 3]</code> и <code>b = [2]</code>, результатом будет <code>[1, 3]</code>.</p>
</div>
