<p>Час має бути у форматі <code>HH:MM</code>.</p>

<pre><code>цифри: 1, 9, 8, 3 =&gt; результат: "19:38"

</code></pre>
<h3 id="notes">Примітки</h3>
<ul>
<li>Результат має бути коректним часом у 24-годинному форматі: від <code>00:00</code> до <code>23:59</code>.</li>
<li>Тестуються лише ті вхідні дані, для яких існують правильні відповіді.</li>

```js
function latestClock(a, b, c, d) {
```
Оголошення функції. Вона приймає 4 цифри.

```js
    let hour = [a, b, c, d];
```
Складаємо цифри в масив, щоб звертатися до них за індексом.

```js
    let comb = [];
```
Порожній масив для всіх двоцифрових чисел, які можна скласти з пар цифр.

```js
    for (let i = 0; i < hour.length; i++) {
        for (let j = 0; j < hour.length; j++) {
```
Два вкладені цикли перебирають усі пари позицій `(i, j)`. `i` відповідає за першу цифру числа, `j` за другу.

```js
            if (i === j) continue;
```
Пропускаємо пари, де обидві позиції збігаються. Інакше одна й та сама цифра використалась би двічі, наприклад `22` з одної двійки.

```js
            comb.push({ value: hour[i] * 10 + hour[j], i, j });
```
Додаємо в `comb` об'єкт: двоцифрове число `value` (наприклад, `1` і `9` дають `19`) та індекси `i`, `j`, з яких воно складене. Індекси потрібні, щоб далі знати, які цифри вже «зайняті».

```js
    let best = null;
```
Тут зберігатиметься найкращий знайдений час. Спершу його немає.

```js
    for (const h of comb.filter((x) => x.value <= 23)) {
```
Беремо лише ті числа, які можуть бути годиною (≤ 23), і по черзі розглядаємо кожне як кандидата `h`.

```js
        const mins = comb.filter(
            (m) =>
                m.value <= 59 &&
                m.i !== h.i &&
                m.i !== h.j &&
                m.j !== h.i &&
                m.j !== h.j,
        );
```
Для кандидата-години шукаємо хвилини. Підходить число, яке ≤ 59 і складене з двох інших позицій, тобто жодна з його позицій `m.i`, `m.j` не збігається з позиціями години `h.i`, `h.j`. Так ми гарантуємо, що кожна цифра використана рівно один раз.

```js
        if (!mins.length) continue;
```
Якщо для цієї години хвилин скласти не можна (приклад: година `21` у випадку `1, 2, 8, 9`), переходимо до наступної.

```js
        const mn = Math.max(...mins.map((m) => m.value));
```
Серед допустимих хвилин беремо найбільшу. `mins.map(...)` витягує самі числа, а `Math.max(...)` вибирає максимум.

```js
        if (!best || h.value > best.hr || (h.value === best.hr && mn > best.mn)) {
            best = { hr: h.value, mn };
        }
```
Оновлюємо найкращий результат, якщо:
- його ще немає, або
- ця година більша за поточну найкращу, або
- година така сама (це буває, коли однакову годину можна скласти з різних індексів, як-от при дублікатах цифр), але хвилини більші.

```js
    return `${String(best.hr).padStart(2, '0')}:${String(best.mn).padStart(2, '0')}`;
```
Формуємо рядок `HH:MM`. `padStart(2, '0')` додає ведучий нуль, щоб `0` стало `00`, а `5` стало `05`.

**Приклад для `(1, 9, 8, 3)`:**
- Допустимі години: `19`, `18`, `13`.
- Для `19` (позиції 0 і 1) лишаються цифри `8` і `3`. З них виходять `83` (більше 59, не підходить) і `38` (підходить), тож `mn = 38` і `best = 19:38`.
- Для `18` виходить хвилина `39`, але година менша, тому `best` не змінюється.
- Для `13` лишаються `9` і `8`: `98` і `89` обидва більші за 59, тому `mins` порожній і цей варіант пропускається.
- Результат: `19:38`.
