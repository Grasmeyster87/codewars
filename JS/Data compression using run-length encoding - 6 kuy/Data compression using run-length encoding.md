<div class="markdown prose max-w-none mb-8" id="description"><p><a href="http://en.wikipedia.org/wiki/Run-length_encoding" data-turbolinks="false" target="_blank">Run-length encoding</a> (RLE) is a very simple form of lossless data compression in which runs of data are stored as a single data value and count.</p>
<p>A simple form of RLE would encode the string <code>"AAABBBCCCD"</code> as <code>"3A3B3C1D"</code> meaning, first there are <code>3 A</code>, then <code>3 B</code>, then <code>3 C</code> and last there is <code>1 D</code>.</p>
<p>Your task is to write a RLE encoder and decoder using this technique. The texts to encode will always consist of only uppercase characters, no numbers.</p>
</div>

<div class="markdown prose max-w-none mb-8" id="description"><p><a href="http://en.wikipedia.org/wiki/Run-length_encoding" data-turbolinks="false" target="_blank">Кодирование длин серий</a> (RLE) — это очень простая форма сжатия данных без потерь, при которой последовательности данных хранятся как одно значение данных и подсчитываются.</p>
<p>Простая форма RLE закодировала бы строку <code>AAABBBCCCD"</code> как <code>3A3B3C1D"</code>, то есть сначала есть <code>3 A</code>, затем <code>3 B</code>, затем <code>3 C</code> и, наконец, <code>1 D</code>.</p>
<p>Ваша задача — написать кодировщик и декодер RLE, используя эту технику.</p> Текст для кодирования всегда будет состоять только из заглавных букв, без цифр.</p>

Як це працює та проходить тести:encode: Регулярний вираз /(.)\1*/g знаходить усі групи однакових символів, що йдуть підряд (наприклад, AAA). Потім функція замінює цю групу на її довжину та сам символ (3A). Це покриває всі базові тести, включаючи AAABBBCCCA -> 3A3B3C1A.  decode: Регулярний вираз /(\d+)(.)/g шукає число (яке може складатися з кількох цифр, як у випадку з 10A), за яким іде один символ. Функція repeat() множить цей символ на отримане число. Це дозволяє успішно проходити як базові тести (1A -> A), так і складніші перевірки Round trip, де кодування і декодування викликаються послідовно одне за одним.  

Метод `replace()` у JavaScript працює надзвичайно гнучко, коли замість простого рядка для заміни ми передаємо **регулярний вираз (RegEx)** та **callback-функцію**.

Давай розберемо обидва підходи під мікроскопом.

---

## 1. Кодування: `input.replace(/(.)\1*/g, (match, char) => ...)`

Цей рядок шукає однакові символи, що йдуть підряд, і замінює їх на кількість + сам символ.

### Регулярний вираз: `/(.)\1*/g`

* `(.)` — **Група захоплення (Capturing group 1).** Крапка `.` означає "будь-який символ". Дужки `()` запам'ятовують цей знайдений символ, щоб ми могли використати його далі.
* `\1` — **Зворотне посилання (Backreference).** Це посилання на те, що ми щойно зловили у першій групі. Воно буквально означає: "шукай точно такий самий символ, який ми знайшли крок тому".
* `*` — **Квантифікатор "нуль або більше".** Вказує, що символ з `\1` може повторюватися багато разів підряд (або жодного, якщо літера одна).
* `g` — **Глобальний прапорець (Global).** Змушує метод пройтися по всьому рядку до кінця, а не зупинятися після першого ж знаходження.

> **Як це читає рушій JS:** "Знайди будь-який символ, запам'ятай його, і захопи разом із ним усі наступні ідентичні символи, що йдуть безперервно".

### Callback-функція: `(match, char) => match.length + char`

Кожного разу, коли регулярка знаходить збіг, вона викликає цю функцію.

* `match` — це весь знайдений рядок (наприклад, `"AAA"`).
* `char` — це значення першої групи захоплення `(.)` (наприклад, `"A"`).

**Приклад для рядка `"AAAB"`:**

1. Знаходить `"AAA"`. Викликає функцію: `("AAA", "A") => "AAA".length + "A"`. Повертає `"3A"`.
2. Знаходить `"B"`. Викликає функцію: `("B", "B") => "B".length + "B"`. Повертає `"1B"`.

## 2. Декодування: `input.replace(/(\d+)(.)/g, (match, count, char) => ...)`

Цей рядок шукає пари "число-літера" і розгортає їх назад у послідовність літер.

### Регулярний вираз: `/(\d+)(.)/g`

Тут у нас є дві окремі групи захоплення:

* `(\d+)` — **Перша група.** `\d` шукає цифру (0-9), а `+` означає "одна або більше". Тобто це успішно знайде і `3`, і `10`, і `999`.
* `(.)` — **Друга група.** Знаходить рівно один будь-який символ, який йде одразу після числа (у нашому випадку — літеру).
* `g` — знову **Глобальний прапорець**, щоб обробити весь рядок.

### Callback-функція: `(match, count, char) => char.repeat(Number(count))`

Цього разу аргументів більше, оскільки у нас дві групи захоплення:

* `match` — весь знайдений шматок (наприклад, `"10A"`).
* `count` — значення першої групи `(\d+)` (наприклад, `"10"`).
* `char` — значення другої групи `(.)` (наприклад, `"A"`).

У тілі функції:

1. `Number(count)` явно перетворює рядок `"10"` у число `10`. *(Хоча метод `repeat` у JS зробив би це неявно, явне перетворення — це хороша практика).*
2. `char.repeat(10)` бере літеру і дублює її 10 разів, генеруючи `"AAAAAAAAAA"`.
