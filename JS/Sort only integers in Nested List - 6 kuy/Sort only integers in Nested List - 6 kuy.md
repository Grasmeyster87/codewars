<div class="markdown prose max-w-none mb-8" id="description"><p>You get some nested lists. Keeping the original structures, sort only elements (integers) inside of the lists. In other words, sorting the intergers only by swapping their positions. </p>
<pre><code>Example
Input   : [[[2, 1], [4, 3]], [[6, 5], [8, 7]]]
Output  : [[[1, 2], [3, 4]], [[5, 6], [7, 8]]]
</code></pre>
<p>Note:
The structures of the lists are regular (symmetrical) and their depths are 3.</p>
</div>

<br> <hr> <br>

<div class="markdown prose max-w-none mb-8" id="description"><p>Даны вложенные списки. Необходимо отсортировать только содержащиеся в них элементы (целые числа), сохранив при этом исходную структуру списков. Иными словами, нужно упорядочить целые числа, меняя их местами.</p>
<pre><code>Пример
Входные данные : [[[2, 1], [4, 3]], [[6, 5], [8, 7]]]
Результат      : [[[1, 2], [3, 4]], [[5, 6], [7, 8]]]
</code></pre>
<p>Примечание:
Структура списков является регулярной (симметричной), а глубина вложенности составляет 3.</p>
</div>
