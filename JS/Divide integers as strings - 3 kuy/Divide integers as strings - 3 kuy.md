## `stripLeadingZeros(s)` — рядки 1-4

Прибирає зайві нулі на початку числа-рядка.

```js
function stripLeadingZeros(s) {
```
Приймає рядок `s`, який представляє невід'ємне ціле число.

```js
  const stripped = s.replace(/^0+/, '');
```
Регулярний вираз `/^0+/` шукає один або більше символів `0` **на самому початку** рядка (`^`) і видаляє їх. Наприклад: `'0042'` → `'42'`, `'0'` → `''`, `'5'` → `'5'`.

```js
  return stripped === '' ? '0' : stripped;
```
Якщо після видалення нулів рядок став порожнім (це сталось із самим `'0'` або `'000'`), повертаємо `'0'`. Інакше — результат без провідних нулів.

## `compare(x, y)` — рядки 7-11

Порівнює два числа-рядки **без провідних нулів**. Повертає `-1` (x<y), `0` (x=y) або `1` (x>y). Знак — умовний, важливий лише сам факт: більше/менше/рівне нулю.

```js
function compare(x, y) {
```

```js
  if (x.length !== y.length) return x.length - y.length;
```
Ключова ідея: якщо в числа без провідних нулів більше цифр — воно автоматично більше. Порівнюємо довжини рядків — це і швидше, і надійніше, ніж парсити число.

```js
  if (x === y) return 0;
```
Якщо довжини однакові й рядки повністю збігаються — числа рівні.

```js
  return x > y ? 1 : -1;
```
Якщо довжини однакові, а рядки різні — можна порівнювати їх **лексикографічно** (як текст, через `>`). Це коректно працює **тільки тому**, що довжини вже гарантовано однакові й немає провідних нулів — тоді порядок символів зліва направо відповідає порядку цифр за значущістю (перша цифра — найстарший розряд).

## `multiplyByDigit(x, d)` — рядки 14-25

Множить велике число-рядок `x` на одну цифру `d` (від 0 до 9) — те саме, що робимо в стовпчик у школі.

```js
function multiplyByDigit(x, d) {
```

```js
  if (d === 0) return '0';
```
Окремий швидкий випадок: множення на 0 завжди дає 0, немає сенсу рахувати.

```js
  let carry = 0;
```
`carry` — перенесення в наступний (старший) розряд, як коли множиш `7*9=63` — пишеш `3`, а `6` переносиш далі.

```js
  let result = '';
```
Сюди накопичуємо цифри результату.

```js
  for (let i = x.length - 1; i >= 0; i--) {
```
Йдемо по цифрах `x` **справа наліво** (від молодшого розряду до старшого) — так само, як множимо вручну.

```js
    const prod = (x.charCodeAt(i) - 48) * d + carry;
```
`x.charCodeAt(i)` дає код символу (наприклад, `'7'` → 55), а `- 48` перетворює його в саме число-цифру (код `'0'` = 48, тому `'7'.charCodeAt(0) - 48 = 7`). Це швидша альтернатива `parseInt(x[i])` або `Number(x[i])`. Множимо поточну цифру на `d` і додаємо перенесення з попереднього кроку.

```js
    result = (prod % 10) + result;
```
`prod % 10` — остача від ділення на 10, тобто одна цифра результату в поточному розряді. Додаємо її **на початок** рядка `result` (бо йдемо справа наліво, а результат читається зліва направо).

```js
    carry = Math.floor(prod / 10);
```
Частина `prod`, яка "не влізла" в один розряд, іде як перенесення в наступну ітерацію (наступний, старший розряд).

```js
  }
  if (carry > 0) result = carry + result;
```
Після проходу по всіх цифрах, якщо лишилось перенесення (наприклад, множили `99*9=891` — після обробки всіх цифр `9` лишається `carry=8`), дописуємо його на початок як ще одну(і) цифру(и).

```js
  return result;
}
```
Повертаємо результат. (Тут провідних нулів виникнути не може, бо `x` вже без них, а `d` — не нуль, окремо обробленим вище.)

## `subtract(x, y)` — рядки 28-48

Віднімає `y` від `x`, за умови `x >= y` (в контексті задачі це завжди так — залишок ніколи не буває меншим за те, що віднімаємо).

```js
function subtract(x, y) {
  let result = '';
  let borrow = 0;
```
`borrow` — позичання з наступного (старшого) розряду, як коли віднімаєш `3 - 7` — доводиться "позичити" 10 зі старшого розряду.

```js
  let i = x.length - 1;
  let j = y.length - 1;
```
`i` та `j` — індекси останніх (молодших) цифр `x` та `y` відповідно. Оскільки `x` може бути довшим за `y` (наприклад, `remainder` довший за `b`), рухаємось по обох з кінця одночасно, але `j` може "закінчитись" раніше.

```js
  while (i >= 0) {
```
Цикл триває, поки не обробимо всі цифри `x` (довшого чи рівного числа).

```js
    const digitX = x.charCodeAt(i) - 48;
    const digitY = j >= 0 ? y.charCodeAt(j) - 48 : 0;
```
Беремо поточну цифру `x`. Для `y` — якщо його цифри вже "закінчились" (`j < 0`, бо `y` коротший), вважаємо, що там `0`.

```js
    let diff = digitX - digitY - borrow;
```
Різниця поточних цифр з урахуванням позичання з попереднього (молодшого) кроку.

```js
    if (diff < 0) {
      diff += 10;
      borrow = 1;
    } else {
      borrow = 0;
    }
```
Якщо різниця від'ємна (наприклад, `3 - 7 = -4`) — позичаємо 10 у старшого розряду (`diff = -4 + 10 = 6`) і запам'ятовуємо, що на наступному кроці треба відняти ще 1 (`borrow = 1`). Якщо різниця невід'ємна — позичання не потрібне.

```js
    result = diff + result;
```
Дописуємо отриману цифру на початок результату (знову ж, бо йдемо справа наліво).

```js
    i--;
    j--;
  }
```
Переходимо до наступних (старших) цифр обох чисел.

```js
  return stripLeadingZeros(result);
}
```
Прибираємо провідні нулі — вони майже завжди з'являються, бо `x` (тобто `remainder`) зазвичай на 1 цифру довший за різницю (наприклад, `10 - 7 = 03` → `3`).

## `divideStrings(a, b)` — рядки 50-84 — головна функція

Реалізує ділення "в стовпчик" на рядках цифр.

```js
function divideStrings(a, b) {
  a = stripLeadingZeros(a);
  b = stripLeadingZeros(b);
```
Прибираємо провідні нулі з обох вхідних чисел одразу — далі весь код працює з "чистими" рядками.

```js
  if (a === '0') return ['0', '0'];
```
Окремий випадок: якщо ділене — нуль, відповідь одразу `['0', '0']` без запуску всього циклу.

```js
  const multiples = ['0'];
  for (let d = 1; d <= 9; d++) {
    multiples.push(multiplyByDigit(b, d));
  }
```
**Оптимізація.** Замість того, щоб на кожному кроці ділення заново рахувати `b*1, b*2, ..., b*9` (а таких кроків стільки, скільки цифр у `a`, тобто до ~200), рахуємо всі 10 множників (`b*0` до `b*9`) **один раз** на початку і зберігаємо в масиві `multiples`. Далі просто беремо готове значення `multiples[d]`.

```js
  let remainder = '0';
  let quotient = '';
```
`remainder` — поточний "робочий" залишок (те, що ділимо на даному кроці). `quotient` — частка, яку будуємо цифра за цифрою.

```js
  for (let i = 0; i < a.length; i++) {
```
Йдемо по цифрах діленого `a` **зліва направо** (на відміну від множення/віднімання) — саме так рахують ділення в стовпчик: беруть цифри одну за одною зверху.

```js
    remainder = stripLeadingZeros(remainder + a[i]);
```
"Зносимо" наступну цифру `a` в кінець поточного залишку (як у школі: "знесли наступну цифру"). Наприклад, якщо `remainder = '3'`, а поточна цифра `'7'`, отримуємо `'37'`. Прибираємо провідні нулі про всяк випадок (актуально на першому кроці, коли `remainder` починається з `'0'`).

```js
    let d = 0;
    for (let k = 9; k >= 0; k--) {
      if (compare(multiples[k], remainder) <= 0) {
        d = k;
        break;
      }
    }
```
Шукаємо чергову цифру частки: **найбільшу** цифру `d` від 9 до 0, для якої `b*d ≤ remainder`. Йдемо від 9 униз і зупиняємось на першій, що підходить — це і є потрібна цифра (бо `b*9 > b*8 > ... > b*0`, тож перше входження знизу вгору... точніше зверху вниз — і є максимум, що влазить).

```js
    quotient += d;
```
Дописуємо знайдену цифру до частки.

```js
    remainder = subtract(remainder, multiples[d]);
  }
```
Оновлюємо залишок: віднімаємо від нього `b*d` — це і є "остача" на даному кроці, яка піде далі в наступну ітерацію (до неї знову "знесеться" наступна цифра `a`).

```js
  return [stripLeadingZeros(quotient), remainder];
}
```
Після обробки всіх цифр `a`: `quotient` містить повну частку (прибираємо можливі провідні нулі — актуально, якщо результат ділення менший за `a` за кількістю значущих цифр, наприклад `4/5 = 0` з нулем на початку), а `remainder` — фінальний залишок (уже без провідних нулів, бо `subtract` це гарантує).

## Експорт — рядки 86-91

```js
divideStrings.stripLeadingZeros = stripLeadingZeros;
divideStrings.compare = compare;
divideStrings.multiplyByDigit = multiplyByDigit;
divideStrings.subtract = subtract;
```
Оскільки функції в JS — це теж об'єкти, можна дописувати їм властивості. Тут кожна допоміжна функція "чіпляється" як властивість на головну `divideStrings`, щоб їх можна було викликати ззовні як `divideStrings.compare(...)` і т.д.

```js
module.exports = divideStrings;
```
Експортуємо саму функцію `divideStrings` (з причепленими властивостями) — так `require(...)` продовжує повертати функцію, яку можна викликати напряму, а всі інші функції доступні як її властивості.
